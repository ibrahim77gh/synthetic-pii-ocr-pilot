      How the documents are generated
      
    
      
    
      
      
      
        
      Values
      
        
      Each page gets one fresh synthetic person from Faker in one of six locales (en_US, en_GB, de_DE, fr_FR, it_IT, nl_NL). Local formats are kept: dates follow the locale with some ISO dates mixed in, postcode and city swap order on EU addresses, and US pages carry SSNs and cards where EU pages carry IBANs. Emails are built from the person's own name, as they usually are in real documents.
      
      
      
      
      
        
      Layouts
      
        
      Three templates: form, invoice and ID-style card. Each varies font (7 families), field order, key wording ("Surname" or "Family name"), boxed or underlined inputs, and colour. Every page also contains text that is not personal data and stays unlabelled on purpose: company names and addresses, invoice and due dates, expiry dates, form references and amounts.
      
      
      
      
      
        
      Scan effects
      
        
      203 of the 300 pages are rotated by up to 1.5°. Pages also get mild blur, contrast and brightness shifts, grain and JPEG compression. Boxes are transformed with the page. Each field stores its rotated four-corner quad and the axis-aligned bbox around it.
      
      
      
      
      
        
      Key–value links
      
        
      Each field also stores the printed label it belongs to (key_text, key_bbox), so the same data can train key–value extraction as well as PII detection.
      
      
      
    
      
  
      

  
      
    
      
      
      Output format
      
      
      One JPEG per page, one JSONL record per page, and a flat Parquet file with one row per field for quick analysis in pandas or polars.

      Reproducibility. Two runs with the same seed produce byte-identical files (303 of 303). Two fixes were needed to get there. Pillow's effect_noise uses its own random generator, which the seed doesn't control, so the grain is now drawn from the seeded one. Faker builds its Italian city list from a Python set, so the order changed with each process's hash seed and the same seed gave different cities. The generator now sorts that list.

      Speech pilot: putting PII spans on the audio timeline
      
      
      This part is a design, not yet built: how labelled text spans get aligned to timestamps in generated audio.
      
    
      
    
        
      
      1. Turn the text into what will be spoken, keeping an offset map
        Written PII isn't spoken as written. j.doe@mail.com becomes "j dot doe at mail dot com", and an IBAN is read in digit groups. I would convert each span to its spoken form and keep a character map from written to spoken offsets, so every label still points at the right words after conversion.
        2. 
      
      2. Generate the audio
        Open-weight TTS on the GPU machine, with several voices and speaking rates per sentence. Each model and voice gets a licence check first. For example, Kokoro-82M is Apache-2.0, but XTTS-v2 is under the Coqui Public Model License, which is non-commercial, so it can't feed the commercial datasets.
        3. 
      
      3. Force-align words to the audio
        Montreal Forced Aligner, or a CTC aligner such as the one in WhisperX, gives start and end times for every spoken word. If the TTS engine reports its own word timings, I would use them and keep the aligner as a cross-check.
        4. 
      
      4. Project each span onto time
        Spoken span, then the words it covers, then [first word start, last word end] with about 30 ms of padding. Each record keeps the written offsets, the spoken offsets and the seconds.
        5. 
      
      5. Check every clip
        Re-transcribe each clip with Whisper and flag clips where the character error rate inside a PII span is over a set limit. Mispronounced IBANs and emails are the usual failure. Also check that timestamps increase and stay inside the clip, flag clips that are unusually slow or fast per character, and listen to a random sample from each voice.
        6. 
    
      
  
      

  
      
    
      
      
      Merging existing text datasets
      
    
      
    
        
      
      • Deduplicate on masked text, not raw text. Two rows that differ only in the name dropped into them are the same sentence. Replacing each span with its label ([GIVENNAME] paid [IBAN]) before hashing catches those duplicates.
        • 
      
      • Exact hashing first, then MinHash-LSH on word shingles for near-duplicates. Set the similarity threshold on a hand-checked sample before applying it.
        • 
      
      • Check that every span is still correct after each normalisation step: text[start:end] == value, so no offset quietly shifts.
        • 
      
      • Carry source dataset, version, licence and original row id through every merge, so any row can be traced and removed if a source licence changes.
        •

      """Generate a synthetic OCR dataset of PII-bearing documents with field-level boxes.

Three templates (form, invoice, ID-style card), six locales. Every PII value is drawn
twice: once on the visible page and once on a hidden index mask with the same transform.
After augmentation the mask gives the true ink extent of each field, which is used to
verify the geometric box labels before anything is written.

Usage:  python generate.py --out data --per-template 100 --seed 1234
"""

@lru_cache(maxsize=None)
def font(name, size):
    return ImageFont.truetype(str(FONT_DIR / name), size)


def fit(draw, text, name, size, max_w):
    while size > 11 and draw.textlength(text, font=font(name, size)) > max_w:
        size -= 1
    return font(name, size)


def ascii_slug(s):
    s = unicodedata.normalize("NFKD", s).encode("ascii", "ignore").decode()
    return "".join(ch for ch in s.lower() if ch.isalnum())


def digits(s):
    return sum(ch.isdigit() for ch in s)


def make_person(fk, loc, rnd, seen):
    """One synthetic identity; values in UNIQUE never repeat across the dataset."""
    while True:
        given, surname = fk.first_name(), fk.last_name()
        dob = fk.date_of_birth(minimum_age=18, maximum_age=85)
        fmt = "%Y-%m-%d" if rnd.random() < 0.15 else DATE_FMT[loc]
        phone = fk.phone_number()
        while not 7 <= digits(phone) <= 15:
            phone = fk.phone_number()
        p = {
            "GIVENNAME": given, "SURNAME": surname, "DATEOFBIRTH": dob.strftime(fmt),
            "EMAIL": f"{ascii_slug(given)}{rnd.choice(['.', '_', ''])}{ascii_slug(surname)}"
                     f"{rnd.choice(['', '', str(rnd.randint(1, 99))])}@{fk.free_email_domain()}",
            "TELEPHONENUM": phone, "STREET": fk.street_address(), "CITY": fk.city(),
            "ZIPCODE": fk.postcode(),
            "IDCARDNUM": fk.bothify(rnd.choice(["??#######", "#########", "?##?#####"])).upper(),
        }
        if loc == "en_US":
            p["SOCIALNUM"] = fk.ssn()
            cc = fk.credit_card_number(card_type=rnd.choice(["visa16", "mastercard"]))
            p["CREDITCARDNUMBER"] = " ".join(cc[i:i + 4] for i in range(0, len(cc), 4))
        else:
            iban = fk.iban()
            p["IBAN"] = " ".join(iban[i:i + 4] for i in range(0, len(iban), 4))
        p = {k: " ".join(v.split()) for k, v in p.items()}  # single line, single spaces
        keys = [(k, p[k].replace(" ", "")) for k in UNIQUE if k in p]
        ident = (given, surname, dob.isoformat())
        if ident not in seen and not any(kv in seen for kv in keys):
            seen.add(ident)
            seen.update(keys)
            p["_dob_iso"], p["_dob_fmt"] = dob.isoformat(), fmt
            return p


class Doc:
    """A page plus a hidden index mask: PII value i is drawn on the mask with pixel value i."""

    def __init__(self, w, h, paper):
        self.w, self.h, self.paper = w, h, paper
        self.img = Image.new("RGB", (w, h), paper)
        self.d = ImageDraw.Draw(self.img)
        self.mask = Image.new("L", (w, h), 0)
        self.md = ImageDraw.Draw(self.mask)
        self.md.fontmode = "1"  # no antialiasing, so mask values stay exact
        self.ents = []

    def text(self, xy, s, f, fill=(70, 70, 70)):
        self.d.text(xy, s, font=f, fill=fill)
        return list(self.d.textbbox(xy, s, font=f))

    def pii(self, xy, s, f, label, key_text=None, key_bbox=None, fill=(25, 25, 30)):
        box = self.text(xy, s, f, fill)
        self.ents.append({"label": label, "text": s, "bbox": box,
                          "key_text": key_text, "key_bbox": key_bbox})
        self.md.text(xy, s, font=f, fill=len(self.ents))
        return box


def paper(rnd):
    return tuple(rnd.randint(244, 255) - k for k in (0, rnd.randint(0, 3), rnd.randint(0, 8)))


def accent(rnd):
    return rnd.choice([(24, 64, 120), (20, 90, 80), (110, 30, 40), (60, 60, 70), (35, 80, 150)])


def fake_date(fk, loc):
    return fk.date_between("-2y", "today").strftime(DATE_FMT[loc])

FORM_TITLES = ["Patient Registration Form", "Customer Onboarding Form", "Membership Application",
               "Tenant Application", "New Account Request"]


def form(p, loc, rnd, fk):
    W, H = 1000, 1414
    doc, fn, acc = Doc(W, H, paper(rnd)), rnd.choice(FONTS), accent(rnd)
    m = rnd.randint(60, 85)
    doc.d.rectangle([0, 0, W, rnd.randint(8, 16)], fill=acc)
    doc.text((m, 48), rnd.choice(FORM_TITLES), font(fn, rnd.randint(32, 40)), fill=acc)
    doc.text((m, 104), f"Form ref {rnd.randint(10000, 99999)}-{rnd.choice('ABCDEFG')}"
                       f"     Received {fake_date(fk, loc)}", font(fn, 17))
    id_key = "SOCIALNUM" if loc == "en_US" else "IDCARDNUM"
    pay_key = "CREDITCARDNUMBER" if loc == "en_US" else "IBAN"
    rows = [[("GIVENNAME", 1), ("SURNAME", 1)], [("DATEOFBIRTH", 1), ("TELEPHONENUM", 1)],
            [("EMAIL", 2)], [("STREET", 2)],
            [("ZIPCODE", 1), ("CITY", 1)] if loc in ZIP_FIRST else [("CITY", 1), ("ZIPCODE", 1)],
            [(id_key, 1)]]
    body = rows[2:]
    rnd.shuffle(body)
    rows = rows[:2] + body
    if rnd.random() < 0.7:
        rows.append([(pay_key, 2)])
    boxed = rnd.random() < 0.6
    gap, col_w = 30, (W - 2 * m - 30) // 2
    y, key_size, val_size = 160, rnd.randint(15, 18), rnd.randint(21, 26)
    for row in rows:
        x = m
        for label, span in row:
            w = col_w * span + gap * (span - 1)
            key = rnd.choice(KEYS[label])
            kb = doc.text((x, y), key.upper() if boxed else key + ":", font(fn, key_size))
            vy = y + key_size + 12
            if boxed:
                doc.d.rectangle([x, vy - 6, x + w, vy + val_size + 14], outline=(150, 150, 155), width=1)
            else:
                doc.d.line([x, vy + val_size + 10, x + w, vy + val_size + 10], fill=(150, 150, 155), width=1)
            vf = fit(doc.d, p[label], fn, val_size, w - 24)
            doc.pii((x + 10, vy), p[label], vf, label, key, kb)
            x += w + gap
        y += key_size + val_size + rnd.randint(52, 70)
    y += 20
    small = font(fn, 16)
    doc.text((m, y), "Preferred contact:   [x] Email   [ ] Phone   [ ] Post", small)
    doc.text((m, y + 34), "I confirm the information above is correct and consent to it being processed",
             small, fill=(110, 110, 110))
    doc.text((m, y + 56), "for the purpose stated in the privacy notice.", small, fill=(110, 110, 110))
    doc.d.line([m, y + 150, m + 330, y + 150], fill=(120, 120, 120))
    doc.text((m, y + 158), "Signature", small)
    doc.text((m + 420, y + 124), fake_date(fk, loc), font(fn, 20))
    doc.text((m + 420, y + 158), "Date", small)
    doc.text((m, H - 50), f"Synthetic sample - not a real record - template form/v1 - page 1 of 1",
             font(fn, 13), fill=(150, 150, 150))
    return doc, "form/v1"


SERVICES = ["Consulting hours", "Annual software licence", "Onboarding workshop", "Support plan (monthly)",
            "Data migration", "Hardware rental", "Training session", "Cloud storage 1 TB", "Maintenance visit"]


def invoice(p, loc, rnd, fk):
    W, H = 1000, 1414
    doc, fn, acc = Doc(W, H, paper(rnd)), rnd.choice(FONTS), accent(rnd)
    m = rnd.randint(60, 85)
    f16, f18 = font(fn, 16), font(fn, 18)
    doc.text((m, 60), fk.company(), font(fn, 26), fill=acc)
    doc.d.multiline_text((m, 100), fk.address(), font=f16, fill=(90, 90, 90), spacing=6)
    doc.text((W - m - 260, 56), "INVOICE", font(fn, 44), fill=acc)
    doc.text((W - m - 260, 120), f"No. INV-{rnd.randint(100000, 999999)}", f16)
    doc.text((W - m - 260, 146), f"Issued {fake_date(fk, loc)}", f16)
    doc.text((W - m - 260, 172), f"Due {fake_date(fk, loc)}", f16)
    y = 250
    kb = doc.text((m, y), rnd.choice(["Bill to", "Billed to", "Customer"]), font(fn, 15), fill=acc)
    vf = font(fn, rnd.randint(19, 22))
    line_h = vf.size + 12
    y += 30
    gx = m
    doc.pii((gx, y), p["GIVENNAME"], vf, "GIVENNAME", "Bill to", kb)
    gx += doc.d.textlength(p["GIVENNAME"] + " ", font=vf)
    doc.pii((gx, y), p["SURNAME"], vf, "SURNAME", "Bill to", kb)
    y += line_h
    doc.pii((m, y), p["STREET"], fit(doc.d, p["STREET"], fn, vf.size, 420), "STREET", "Bill to", kb)
    y += line_h
    first, second = ("ZIPCODE", "CITY") if loc in ZIP_FIRST else ("CITY", "ZIPCODE")
    sep = " " if loc in ZIP_FIRST else ", "
    doc.pii((m, y), p[first], vf, first, "Bill to", kb)
    doc.pii((m + doc.d.textlength(p[first] + sep, font=vf), y), p[second], vf, second, "Bill to", kb)
    y += line_h
    doc.pii((m, y), p["EMAIL"], vf, "EMAIL", "Bill to", kb)
    y += line_h
    doc.pii((m, y), p["TELEPHONENUM"], vf, "TELEPHONENUM", "Bill to", kb)
    y += line_h + 50
    cols = [m, m + 470, m + 580, W - m - 140]
    doc.d.rectangle([m - 10, y - 8, W - m + 10, y + 30], fill=acc)
    for x, h in zip(cols, ["Description", "Qty", "Unit", "Amount"]):
        doc.d.text((x, y), h, font=f16, fill=(255, 255, 255))
    y += 48
    total = 0.0
    for svc in rnd.sample(SERVICES, rnd.randint(3, 6)):
        q, u = rnd.randint(1, 12), round(rnd.uniform(20, 900), 2)
        total += q * u
        for x, s in zip(cols, [svc, str(q), f"{u:,.2f}", f"{q * u:,.2f}"]):
            doc.text((x, y), s, f16)
        y += 34
        doc.d.line([m, y - 8, W - m, y - 8], fill=(220, 220, 220))
    vat = total * 0.2
    for i, (k, v) in enumerate([("Subtotal", total), ("VAT 20%", vat), ("Total due", total + vat)]):
        doc.text((cols[2], y + 16 + i * 32), k, f18 if i < 2 else font(fn, 20))
        doc.text((cols[3], y + 16 + i * 32), f"{v:,.2f}", f18 if i < 2 else font(fn, 20))
    y += 160
    pay = "CREDITCARDNUMBER" if loc == "en_US" else "IBAN"
    key = "Paid by card" if pay == "CREDITCARDNUMBER" else "Direct debit from IBAN"
    kb = doc.text((m, y), key, f16, fill=acc)

def rotate_pts(pts, angle, w, h, nw, nh):
    """Forward map for PIL's rotate(angle, expand=True): counter-clockwise about the centre."""
    a = math.radians(angle)
    c, s = math.cos(a), math.sin(a)
    return [((x - w / 2) * c + (y - h / 2) * s + nw / 2, -(x - w / 2) * s + (y - h / 2) * c + nh / 2)
            for x, y in pts]


def corners(b):
    return [(b[0], b[1]), (b[2], b[1]), (b[2], b[3]), (b[0], b[3])]


def aabb(q):
    xs, ys = [x for x, _ in q], [y for _, y in q]
    return [math.floor(min(xs)), math.floor(min(ys)), math.ceil(max(xs)), math.ceil(max(ys))]


def augment(doc, rnd):
    img, mask, w, h = doc.img, doc.mask, doc.w, doc.h
    angle = round(rnd.uniform(-1.5, 1.5), 2) if rnd.random() < 0.7 else 0.0
    if angle:
        bed = getattr(doc, "bed", None) or (rnd.randint(190, 215),) * 3
        img = img.rotate(angle, resample=Image.BICUBIC, expand=True, fillcolor=bed)
        mask = mask.rotate(angle, resample=Image.NEAREST, expand=True, fillcolor=0)
    nw, nh = img.size
    for e in doc.ents:
        for k in ("bbox", "key_bbox"):
            if e[k] is None:
                continue
            q = rotate_pts(corners(e[k]), angle, w, h, nw, nh)
            if k == "bbox":
                e["quad"] = [[round(x, 1), round(y, 1)] for x, y in q]
            e[k] = aabb(q)
    blur = rnd.choice([0, 0, 0.4, 0.7])
    if blur:
        img = img.filter(ImageFilter.GaussianBlur(blur))
    img = ImageEnhance.Contrast(img).enhance(round(rnd.uniform(0.85, 1.1), 2))
    img = ImageEnhance.Brightness(img).enhance(round(rnd.uniform(0.96, 1.04), 2))
    noise = round(rnd.uniform(0, 0.05), 3)
    if noise:
        # seeded noise; Image.effect_noise has its own unseeded RNG and breaks reproducibility
        grain = Image.frombytes("L", (nw, nh), rnd.randbytes(nw * nh)).convert("RGB")
        img = Image.blend(img, grain, noise)
    return img, mask, {"angle": angle, "blur": blur, "noise": noise, "jpeg_quality": rnd.randint(62, 92)}


def render_check(ents, mask, tol=2):
    """True ink box of each field (from the mask) must sit inside its label box (+tol px)."""
    out = []
    for i, e in enumerate(ents, start=1):
        ink = mask.point(lambda v, i=i: 255 if v == i else 0).getbbox()
        b = e["bbox"]
        ok = ink is not None and ink[0] >= b[0] - tol and ink[1] >= b[1] - tol \
            and ink[2] <= b[2] + tol and ink[3] <= b[3] + tol
        out.append(ok)
    return out


def split_for(ident):
    v = int(hashlib.sha1("|".join(ident).encode()).hexdigest(), 16) % 10
    return "test" if v == 0 else "validation" if v == 1 else "train"

      """Validate a generated dataset from disk only (images + metadata.jsonl) and write qc_report.json.

Usage:  python validate.py --data data
Exit code 1 if any check fails.
"""
import argparse
import hashlib
import json
import math
import re
from collections import Counter, defaultdict
from datetime import datetime
from pathlib import Path

from PIL import Image

UNIQUE = ["EMAIL", "TELEPHONENUM", "IDCARDNUM", "SOCIALNUM", "IBAN", "CREDITCARDNUMBER"]


def iban_ok(s):
    s = s.replace(" ", "")
    n = "".join(str(int(c, 36)) for c in s[4:] + s[:4])
    return bool(re.fullmatch(r"[A-Z]{2}\d{2}[A-Z0-9]{8,30}", s)) and int(n) % 97 == 1


def luhn_ok(s):
    d = [int(c) for c in s.replace(" ", "")][::-1]
    return len(d) >= 13 and sum(x if i % 2 == 0 else (x * 2 - 9 if x > 4 else x * 2) for i, x in enumerate(d)) % 10 == 0


def dob_ok(e):
    try:
        return datetime.strptime(e["text"], e["source_format"]).date().isoformat() == e["normalized"]
    except (KeyError, ValueError):
        return False


VALIDATORS = {
    "EMAIL": lambda e: re.fullmatch(r"[a-z0-9._]+@[a-z0-9.-]+\.[a-z]{2,}", e["text"]) is not None,
    "TELEPHONENUM": lambda e: 7 <= sum(c.isdigit() for c in e["text"]) <= 15,
    "DATEOFBIRTH": dob_ok,
    "IBAN": lambda e: iban_ok(e["text"]),
    "CREDITCARDNUMBER": lambda e: luhn_ok(e["text"]),
    "SOCIALNUM": lambda e: re.fullmatch(r"\d{3}-\d{2}-\d{4}", e["text"]) is not None,
    "IDCARDNUM": lambda e: re.fullmatch(r"[A-Z0-9]{9}", e["text"]) is not None,
    "ZIPCODE": lambda e: any(c.isdigit() for c in e["text"]),
    "GIVENNAME": lambda e: e["text"] != "" and not any(c.isdigit() for c in e["text"]),
    "SURNAME": lambda e: e["text"] != "" and not any(c.isdigit() for c in e["text"]),
    "CITY": lambda e: e["text"] != "",
    "STREET": lambda e: e["text"] != "",
}


def derotated_boxes(ents):
    """Undo the page rotation (read from the quads) so overlap is tested on upright boxes."""
    (x0, y0), (x1, y1) = ents[0]["quad"][0], ents[0]["quad"][1]
    a = math.atan2(y1 - y0, x1 - x0)
    c, s = math.cos(-a), math.sin(-a)
    out = []
    for e in ents:
        pts = [(x * c - y * s, x * s + y * c) for x, y in e["quad"]]
        out.append((min(p[0] for p in pts), min(p[1] for p in pts), max(p[0] for p in pts), max(p[1] for p in pts)))
    return out


def ink_ratio(gray, b):
    crop = gray.crop(b)
    hist = crop.histogram()
    return sum(hist[:140]) / max(1, crop.width * crop.height)


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--data", default="data")
    root = Path(ap.parse_args().data)
    rows = [json.loads(line) for line in open(root / "metadata.jsonl", encoding="utf-8")]
    fails = defaultdict(list)
    img_hashes, idents, uniq = {}, {}, defaultdict(dict)
    min_ink, labels = 1.0, Counter()
    for r in rows:
        path = root / r["file_name"]
        if not path.exists():
            fails["missing_file"].append(r["doc_id"])
            continue
        raw = path.read_bytes()
        h = hashlib.sha256(raw).hexdigest()
        if h in img_hashes:
            fails["duplicate_image"].append((img_hashes[h], r["doc_id"]))
        img_hashes[h] = r["doc_id"]
        im = Image.open(path)
        if im.size != (r["width"], r["height"]):
            fails["size_mismatch"].append(r["doc_id"])
        gray = im.convert("L")
        ident = r["person_id"]
        if ident in idents:
            fails["duplicate_identity"].append((idents[ident][0], r["doc_id"]))
        idents[ident] = (r["doc_id"], r["split"])
        for e in r["entities"]:
            labels[e["label"]] += 1
            x0, y0, x1, y1 = e["bbox"]
            if not (0 <= x0 < x1 <= r["width"] and 0 <= y0 < y1 <= r["height"]):
                fails["out_of_bounds"].append((r["doc_id"], e["label"]))
            if x1 - x0 < 3 or y1 - y0 < 3:
                fails["degenerate_box"].append((r["doc_id"], e["label"]))
            if not VALIDATORS[e["label"]](e):
                fails["format:" + e["label"]].append((r["doc_id"], e["text"]))
            ink = ink_ratio(gray, e["bbox"])
            min_ink = min(min_ink, ink)
            if ink < 0.02:
                fails["no_visible_ink"].append((r["doc_id"], e["label"], round(ink, 3)))
            if e["label"] in UNIQUE:
                v = e["text"].replace(" ", "")
                if v in uniq[e["label"]]:
                    fails["duplicate_value:" + e["label"]].append((uniq[e["label"]][v][0], r["doc_id"]))
                uniq[e["label"]][v] = (r["doc_id"], r["split"])
        boxes = derotated_boxes(r["entities"])
        for i in range(len(boxes)):
            for j in range(i + 1, len(boxes)):
                a, b = boxes[i], boxes[j]
                if min(a[2], b[2]) - max(a[0], b[0]) > 1 and min(a[3], b[3]) - max(a[1], b[1]) > 1:
                    fails["overlapping_boxes"].append((r["doc_id"], r["entities"][i]["label"], r["entities"][j]["label"]))
    # identities and unique values are generated per document, so a split is leak-free if no
    # value seen in test/validation also appears in train
    split_of = {r["doc_id"]: r["split"] for r in rows}
    leaks = 0
    for label, vals in uniq.items():
        by_val = defaultdict(set)
        for r in rows:
            for e in r["entities"]:
                if e["label"] == label:
                    by_val[e["text"].replace(" ", "")].add(split_of[r["doc_id"]])
        leaks += sum(len(s) > 1 for s in by_val.values())
    if leaks:
        fails["split_leakage"].append(leaks)
    gen = json.loads((root / "generation_log.json").read_text())
    report = {
        "documents": len(rows),
        "pii_fields": sum(labels.values()),
        "by_doc_type": Counter(r["doc_type"] for r in rows),
        "by_locale": Counter(r["locale"] for r in rows),
        "by_split": Counter(r["split"] for r in rows),
        "by_label": labels,
        "rotated_docs": sum(r["render"]["angle"] != 0 for r in rows),
        "render_check": f"{gen['render_ok']}/{gen['fields']}",
        "min_ink_ratio": round(min_ink, 3),
        "checks": ["files exist, sizes match", "boxes in bounds, non-degenerate",
                   "no overlapping PII boxes (rotation undone)", "format validators per label",
                   "visible ink inside every box", "no duplicate images (sha256)", "no duplicate identities",
                   "unique fields never repeat", "no value crosses splits"],
        "failures": {k: len(v) for k, v in fails.items()},
        "failure_examples": {k: v[:5] for k, v in fails.items()},
    }
    (root / "qc_report.json").write_text(json.dumps(report, indent=2, ensure_ascii=False))
    print(json.dumps({k: report[k] for k in ("documents", "pii_fields", "render_check", "min_ink_ratio", "failures")}))
    raise SystemExit(1 if fails else 0)


if __name__ == "__main__":
    main()
